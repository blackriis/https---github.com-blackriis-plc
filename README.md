# ระบบวิเคราะห์ข้อมูลนักเรียน RT/NT - v19

เวอร์ชันนี้ปรับปรุงกราฟใยแมงมุมรายบุคคลให้แสดง 2 ชุดข้อมูลชัดเจนเสมอ:

- คะแนนนักเรียน
- ค่าเฉลี่ยโรงเรียน

## การอัปเดต
1. เปิด Apps Script เดิม
2. แทนที่ไฟล์ `Code.gs` ด้วยไฟล์ใหม่
3. แทนที่ไฟล์ `Index.html` ด้วยไฟล์ใหม่
4. กด Save
5. ไปที่ Deploy > Manage deployments
6. เลือก Edit
7. เลือก Version: New version
8. กด Deploy
9. เปิด Web App URL ใหม่

## หมายเหตุ
ถ้าเปิด URL เดิมแล้วไม่เปลี่ยน ให้ refresh แบบล้าง cache หรือเปิดใน incognito


## v28 (Speed & Performance Optimization & Large Student UI)
- **Fast Sheet Inspection**: ตรวจสอบหัวตารางเฉพาะช่วงแถวบนสุด (20 แถวแรก) ก่อนอ่านข้อมูลทั้งชีต เพื่อข้ามชีตที่ไม่เกี่ยวข้องอย่างรวดเร็ว
- **Server Memoization**: แคชข้อมูลการอ่านประมวลผลบน Server ในความทรงจำชั่วคราว ลดเวลาการดึงข้อมูลซ้ำ
- **Instant Student Switch**: สลับดูข้อมูลนักเรียนรายบุคคล (Dropdown/คลิกตาราง) ได้ทันที 0 วินาที โดยประมวลผลบน Client (ไม่ต้องรอส่ง Request ไปยัง Google Server)
- **Instant Tab Switching**: สลับแท็บรายงาน (RT / NT / O-NET) ได้ทันทีเมื่อโหลดข้อมูลครั้งแรกเสร็จสิ้น
- **Large Student UI**: เพิ่มระบบค้นหารายชื่อ (Search Box), กรองตามระดับคุณภาพ (ดีมาก/ดี/พอใช้/ปรับปรุง), แบ่งหน้า (Pagination 15/25/50/100 คน), Sticky Header หัวตาราง และเน้นสีแถวนักเรียนที่กำลังเลือกดูวิเคราะห์อย่างชัดเจน
- **Manual Sheet Refresh**: เพิ่มปุ่ม "🔄 อัปเดตข้อมูลชีต" ในส่วนหัวของหน้าเว็บ เพื่อให้กดล้างแคชและบังคับอ่านข้อมูลล่าสุดจาก Google Sheet ได้ทุกเมื่อ หากมีการแก้ไขคะแนนในชีต
