# ระบบวิเคราะห์ข้อมูลนักเรียน RT / NT / O-NET

เว็บแอปสำหรับอ่านผลการประเมินจาก **Google Sheets** แล้วสรุปภาพรวมโรงเรียนและรายบุคคล ได้แก่ คะแนนเฉลี่ย ระดับคุณภาพ กราฟ และแนวทางพัฒนา ใช้ได้กับข้อมูล RT, NT และ O-NET ที่อยู่ในไฟล์ชีตเดียวกัน

> สำหรับผู้เริ่มต้น: ไม่ต้องติดตั้งโปรแกรมในเครื่อง ใช้บัญชี Google และเว็บเบราว์เซอร์ได้เลย

## ระบบทำอะไรได้บ้าง

- ตรวจหาชีตผล RT, NT และ O-NET โดยอัตโนมัติ
- ดูภาพรวมและสลับรายงานแต่ละประเภทได้ทันทีหลังข้อมูลโหลดครั้งแรก
- ค้นหา กรองระดับคุณภาพ และแบ่งหน้ารายชื่อนักเรียน
- ดูจุดเด่น จุดที่ควรพัฒนา และกราฟเปรียบเทียบคะแนนนักเรียนกับค่าเฉลี่ยโรงเรียน
- กด **อัปเดตข้อมูลชีต** เพื่อล้างข้อมูลชั่วคราวและอ่านคะแนนล่าสุด
- ส่งออกภาพรวมเป็น PDF ขนาด A4
- ใช้ AI ช่วยร่างข้อเสนอแนะได้ (เป็นทางเลือก ต้องตั้งค่า API key เอง)

## สิ่งที่ต้องเตรียม

1. บัญชี Google ที่สามารถสร้างหรือแก้ไข Google Sheets ได้
2. ไฟล์คะแนนที่แปลงเป็น **Google Sheets** แล้ว
3. ไฟล์จากโฟลเดอร์นี้ 2 ไฟล์: `Code.gs` และ `Index.html`
4. Google Chrome หรือเบราว์เซอร์รุ่นปัจจุบัน

## เตรียมข้อมูลใน Google Sheets

1. เปิด Google Drive แล้วอัปโหลดไฟล์ผลคะแนน หากเป็น `.xlsx` ให้เปิดไฟล์นั้นและเลือก **ไฟล์ → บันทึกเป็น Google ชีต**
2. เปิด Google Sheets ที่แปลงแล้ว ตรวจว่าแต่ละแท็บมีข้อมูลผลสอบจริง
3. ชีตที่จะให้ระบบอ่านควรมีทั้งข้อความบ่งชี้ประเภทข้อมูล เช่น `RT`, `NT`, `O-NET`, `R-School` หรือ `คุณภาพผู้เรียน` และมีหัวคอลัมน์อย่างน้อยหนึ่งรายการ เช่น **ชื่อ-สกุล**, **เลขที่นั่งสอบ** หรือ **ลำดับ**

ระบบจะข้ามแท็บที่ไม่ใช่ผลสอบ จึงไม่จำเป็นต้องลบชีตอื่นออกจากไฟล์

> หมายเหตุ: ข้อมูล RT ใช้คะแนนเต็ม **50 คะแนน** ควรตรวจสอบให้คะแนนดิบและคะแนนร้อยละในชีตสอดคล้องกันก่อนเปิดใช้รายงาน

## ติดตั้งครั้งแรก

### 1) เปิด Apps Script จากไฟล์คะแนน

เปิด Google Sheets ที่เตรียมไว้ แล้วเลือก **ส่วนขยาย → Apps Script** อย่าสร้าง Apps Script แยกจากไฟล์คะแนน เพราะระบบนี้อ่านข้อมูลจากชีตที่ผูกอยู่กับสคริปต์

### 2) วางไฟล์ `Code.gs`

1. ในแถบ **ไฟล์** ให้เปิด `Code.gs`
2. เลือกเนื้อหาทั้งหมดแล้วลบออก
3. เปิด `Code.gs` จากโฟลเดอร์นี้ คัดลอกทั้งหมด และวางลงใน Apps Script
4. กดบันทึก

### 3) สร้างและวางไฟล์ `Index.html`

1. กดปุ่ม **+** ข้างหัวข้อไฟล์ แล้วเลือก **HTML**
2. ตั้งชื่อว่า `Index` เท่านั้น — ระบบจะเติม `.html` ให้เอง
3. ลบโค้ดตัวอย่างทั้งหมด
4. คัดลอกเนื้อหาจาก `Index.html` ในโฟลเดอร์นี้มาวาง แล้วกดบันทึก

เมื่อเสร็จ แถบไฟล์ควรมี `Code.gs` และ `Index.html`

### 4) เผยแพร่เป็นเว็บแอป

1. กด **Deploy → New deployment**
2. กดไอคอนรูปเฟืองและเลือก **Web app**
3. ตั้งค่า **Execute as** เป็นบัญชีเจ้าของไฟล์
4. ที่ **Who has access** ให้เลือกเฉพาะกลุ่มที่จำเป็นต้องใช้ข้อมูล เช่น เฉพาะคุณ หรือผู้ใช้ในหน่วยงาน ก่อนเปิดให้กว้างกว่านั้น
5. กด **Deploy** และทำขั้นตอนอนุญาตสิทธิ์ของ Google ให้ครบ
6. คัดลอกลิงก์ที่ลงท้ายด้วย `/exec` แล้วเปิดในเบราว์เซอร์

ครั้งแรก Google อาจแสดงหน้าจอขออนุญาต เพราะสคริปต์ต้องอ่าน Google Sheets ของคุณ ให้ตรวจว่ากำลังใช้บัญชีและโปรเจ็กต์ที่ถูกต้องก่อนกดอนุญาต

## ตรวจสอบหลังติดตั้ง

เมื่อเปิดลิงก์เว็บแอปแล้ว ให้ตรวจ 4 ข้อนี้ก่อนใช้งานจริง

- เห็นชื่อโรงเรียนและรายงาน RT / NT / O-NET ที่มีอยู่ในชีต
- คลิกชื่อนักเรียนแล้วมีข้อมูลรายบุคคลและกราฟแสดงขึ้น
- แก้ไขคะแนนทดสอบหนึ่งรายการในชีต แล้วกด **อัปเดตข้อมูลชีต** ในหน้าเว็บ
- กด **Export PDF A4** และตรวจข้อความภาษาไทย ตาราง และจำนวนหน้าของ PDF ที่ดาวน์โหลด

## การใช้งานประจำ

| ต้องการทำอะไร | วิธีทำ |
| --- | --- |
| ดูผลสอบแต่ละประเภท | เลือกแท็บ RT, NT หรือ O-NET ด้านบนของรายงาน |
| หานักเรียน | พิมพ์ชื่อหรือข้อมูลที่มีในช่องค้นหา แล้วเลือกจากตาราง |
| ดูรายบุคคล | คลิกแถวนักเรียนหรือเลือกจากรายการ ระบบจะแสดงกราฟและข้อเสนอแนะ |
| แก้คะแนนในชีตแล้ว | กลับไปหน้าเว็บและกด **อัปเดตข้อมูลชีต** |
| บันทึกรายงาน | กด **Export PDF A4** จากส่วนภาพรวมโรงเรียน |

## อัปเดตเป็นเวอร์ชันใหม่

1. เปิด **ส่วนขยาย → Apps Script** จาก Google Sheets เดิม
2. วางเนื้อหาใหม่ทับทั้ง `Code.gs` และ `Index.html` แล้วบันทึก
3. ไปที่ **Deploy → Manage deployments**
4. กดแก้ไขการเผยแพร่เดิม เลือก **New version** แล้วกด Deploy
5. เปิดลิงก์ `/exec` เดิมใหม่ หากยังเห็นหน้าเก่าให้รีโหลดแบบล้างแคช หรือเปิดหน้าต่างไม่ระบุตัวตน

การแก้ไขการเผยแพร่เดิมช่วยให้ใช้ลิงก์เดิมต่อได้

## ตั้งค่า AI (ทางเลือก)

หากต้องการให้ระบบสร้างข้อความเสนอแนะแนวทางพัฒนาด้วย AI ให้เพิ่ม Script Property ชื่อ `OPENAI_API_KEY` ใน **Project Settings → Script properties** แล้ววาง API key ของ OpenAI เป็นค่า

อย่าใส่ API key ลงใน `Code.gs`, `Index.html`, Google Sheets หรือเอกสารที่แชร์ให้ผู้อื่น การใช้ AI อาจมีค่าใช้จ่ายตามบัญชีผู้ให้บริการ และระบบยังใช้งานส่วนวิเคราะห์หลักได้แม้ไม่ตั้งค่า key

## ความปลอดภัยของข้อมูลนักเรียน

- ตั้งสิทธิ์เข้าถึงเว็บแอปเท่าที่จำเป็น เพราะรายงานมีข้อมูลผลการเรียน
- อย่าส่งลิงก์ `/exec` ในพื้นที่สาธารณะเมื่อไม่ได้ตั้งใจเผยแพร่ข้อมูล
- ตรวจข้อมูลและ PDF ก่อนส่งต่อ โดยเฉพาะเมื่อนำไปใช้รายงานภายนอก
- สำรอง Google Sheets ต้นฉบับก่อนแก้ไขข้อมูลจำนวนมาก
